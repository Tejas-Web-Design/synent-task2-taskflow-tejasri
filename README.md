🚀 Overview

TaskFlow is a modern SaaS landing page that helps teams organize projects, collaborate efficiently, and boost productivity. The project focuses on clean UI/UX, responsiveness, and interactive user experience.

This project was developed as part of the Synent Technologies Web Development Internship Program.
